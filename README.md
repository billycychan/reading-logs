# Reading Logs

A personal knowledge base for reading progress, chapter notes, evolving
summaries, and practical takeaways from books I read.

## Books

| Book | Author | Status | Notes |
| --- | --- | --- | --- |

## Organization

Each book has its own directory under `books/`. A typical entry contains:

- `chapter-notes.md` for source-grounded chapter summaries;
- `summary.md` for an evolving whole-book synthesis;
- `takeaways.md` for personal reactions and applications.

Use [BOOK_TEMPLATE.md](BOOK_TEMPLATE.md) when adding another title.

## Content policy

This repository contains original notes, summaries, and reflections. It does
not contain ebook files, scanned pages, or substantial reproductions of source
texts. Source materials remain outside version control.

Some summaries may be drafted with AI assistance and are reviewed against the
source by the repository owner.
